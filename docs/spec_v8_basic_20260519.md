# note分析 Basic v8 仕様書 (2026/05/19 更新)

## 1. 概要
noteの公式統計APIからデータを取得し、自身の記事のパフォーマンスを可視化するStreamlitアプリケーション。
「ログイン制限（reCAPTCHA）の完全回避」および「1,500件を超える大量データの安全な全件取得」をサポートし、個人クリエイターの分析を強力に支援する。

## 2. システム構成
- **言語**: Python 3.10+
- **フレームワーク**: Streamlit
- **データベース**: 
    - ローカル：SQLite (`note_dashboard.db`)
    - クラウド：Neon (PostgreSQL)
- **主なライブラリ**: pandas, plotly, requests, psycopg2-binary, python-dotenv, stripe

## 3. 主要機能
### 3.1 認証・取得
- **note認証 (クッキーJSON方式)**: reCAPTCHA制限を回避するため、ブラウザ拡張機能「Cookie-Editor」で取得したクッキーJSONを直接UIに入力し、requests.Sessionに適用する認証方式へ移行。メールアドレス・パスワードでの直接ログインがブロックされた環境でも確実に取得可能。
- **統計取得**: 統計API（累計PV/スキ/コメント）の全件取得。
- **二重の防衛装置 (無限ループ防止)**:
    - **安全装置①（重複排除）**: (記事ID, 記事タイトル) の複合識別子を監視し、同一ページ内で新しい記事が検出されない場合はループ完了。
    - **安全装置②（PVゼロ終端）**: PV順ソートで取得するため、取得データのPV合計値が0になった瞬間に終端と判定して安全に終了。

### 3.2 データ表示（ダッシュボード）
- **サマリー**: 公開記事数、累計総ビュー数（前回比付き）、累計総スキ数。
- **全体累計ビュー推移**: 全記事合計の折れ線グラフ。
- **ランキング**: 累計ランキング、および「本日の伸び」ランキング。
- **個別推移**: 各記事ごとの詳細推移（ホバー詳細付き）。

### 3.3 収益化・自動承認 (Cloudモードのみ)
- **Stripe連携**: 月額300円のサブスクリプション制。
- **全自動同期**: ログインのたびにStripe APIで支払い状況を確認。有効な期間中のみ自動でアクセスを許可。
- **クーポン対応**: `FREE30` 等のプロモーションコードに対応。

## 4. セキュリティとプライバシー
- **クッキーの安全性**: 入力されたクッキーデータは接続セッション構築時のみ使用され、悪用や外部送信は行われない。
- **データ分離**: 暗号化された `user_id` により、同一テーブル内でも他人のデータは閲覧不能。

## 5. 実行モード
### 5.1 ローカル配布モード (EXEビルド)
- **DATABASE_URL未設定**: ログイン画面やStripe案内をスキップし、直接ローカルのSQLiteに接続して動作。
- **v3 パッケージ**: `note_dashboard_v3.exe` としてビルドされ、一切のPython環境がない一般Windows環境でもダブルクリックだけで起動可能。
