# Development Log - 2026-02-28

## 実施内容: note認証仕様変更への対応とEXE版ソースコードの刷新

### 1. note.com 認証エラーの緊急修正
- **事象**: 2026/02/27発生の認証仕様変更（User-Agentチェック等の強化）により、ログインおよびデータ取得が不可となった。
- **対策**: 
    - `noteAPIv8_steamlitV5.py` 等に `DEFAULT_HEADERS` を導入。
    - ログインPOSTの前に初期Cookieを取得するフローを全アプリに適用。
- **結果**: 正常にログインおよびデータ取得機能が復旧したことを確認。

### 2. EXE版（v2）向けソースコードの更新

- **修正**: ユーザーIDがメールアドレスハッシュ（16桁）とDB上のUUIDで混在していた問題を修正。
- **統合**: 誤ってハッシュIDに保存された過去データをUUIDへ統合マイグレーションし、グラフの二重カウント問題を解消した。
